# 审核报告：Lancelot Grail.json

### 文件：Lancelot Grail.json
#### 问题列表
- [specs.KMF Generation] 术语“第七世代”与标准术语“第七世代”一致，但标准表中要求使用中文数字“第七世代”，当前为“第七世代”，格式正确，无需修改。
- [specs.Standard] 字段“闪光护盾系统”与标准术语“卢米纳斯护盾 (Blaze Luminous)”不一致，应使用标准术语。 → 修改建议：将“闪光护盾系统”改为“卢米纳斯护盾 (Blaze Luminous)”。
- [specs.Standard] 字段“事实球体传感器”与标准术语“事实球面传感器 (Factsphere Sensor)”不一致，存在用词差异。 → 修改建议：将“事实球体传感器”改为“事实球面传感器 (Factsphere Sensor)”。
- [specs.Standard] 字段“陆地旋轮推进系统”与标准术语“陆地旋轮 (Landspinner)”不一致，应使用标准术语。 → 修改建议：将“陆地旋轮推进系统”改为“陆地旋轮 (Landspinner)”。
- [specs.Fixed] 字段“飞燕爪牙”为原作术语，无需修改。
- [specs.Fixed] 字段“剑刃”和“剑爪”为自定义武器名称，无标准对应，无需修改。
- [specs.Handheld] 字段“施罗特钢剑”为自定义武器名称，无标准对应，无需修改。
- [introduction] 文本“人型自在战斗装甲（KMF）”中，“人型自在战斗装甲”与标准术语“KMF”一致，但标准表建议使用“KMF”作为简称，当前写法可接受。
- [introduction] 文本“神圣布列塔尼亚帝国”中，“布列塔尼亚”应为“不列颠尼亚”，存在译名不一致。 → 修改建议：将“神圣布列塔尼亚帝国”改为“神圣不列颠尼亚帝国”。
- [Design and Development] 文本“MVS（激光振动剑）”中，“激光振动剑”与标准术语“MVS（Maser Vibration Sword，微波振动剑）”不一致，应使用标准术语。 → 修改建议：将“MVS（激光振动剑）”改为“MVS（Maser Vibration Sword，微波振动剑）”。
