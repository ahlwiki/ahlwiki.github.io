# 审核报告：Akatsuki Flight-Enabled Version.json

### 文件：Akatsuki Flight-Enabled Version.json
#### 问题列表
- [specs.Classification] 术语“量产型KMF”与标准名词对应表中的“人型自在战斗装甲 → KMF”或“Knightmare Frame → KMF”不一致。建议修改为“量产型Knightmare Frame”或“量产型人型自在战斗装甲”。
- [specs.KMF Generation] 术语“相当于第七世代”与标准名词对应表中的“第7世代 → 第七世代”不一致。建议修改为“相当于第七世代”或“第七世代”。
- [specs.Standard] 术语“陆地旋轮推进系统”与标准名词对应表中的“陆地旋轮推进系统 → 陆地旋轮 (Landspinner)”不一致。建议修改为“陆地旋轮 (Landspinner)”。
- [specs.Standard] 术语“飞翔滑走翼”与标准名词对应表中的“悬浮背包 → 浮空单元（Float Unit）”不一致。建议修改为“浮空单元（Float Unit）”。
- [specs.Fixed] 术语“飞燕爪式钩锚”与标准名词对应表中的“闪光护盾系统 → 卢米纳斯护盾 (Blaze Luminous)”等无直接对应，但“飞燕爪式钩锚”在《叛逆的鲁鲁修》中通常称为“飞燕爪锚”或“钩锚”，建议统一为“飞燕爪锚”。
- [specs.Handheld] 术语“辐射波导弹”与标准名词对应表中的“MVS → MVS（Maser Vibration Sword，微波振动剑）”等无直接对应，但“辐射波导弹”在《叛逆的鲁鲁修》中通常称为“辐射波动导弹”或“辐射波导弹”，建议根据原作设定统一为“辐射波动导弹”。
- [specs.Anime] 术语“Code Geass 叛逆的鲁鲁修”与标准名词对应表中的“Code Geass 叛逆的鲁鲁修”一致，但“叛逆的鲁鲁修”在中文语境中常称为“反叛的鲁路修”，建议统一为“Code Geass 反叛的鲁路修”。
- [introduction] 术语“飞翔滑走翼”与标准名词对应表中的“悬浮背包 → 浮空单元（Float Unit）”不一致。建议修改为“浮空单元（Float Unit）”。
- [Design and Specifications] 术语“月下”与标准名词对应表中的“第3世代 → 第三世代”等无直接对应，但“月下”是机体名称，无需修改。
- [Design and Specifications] 术语“红莲可翔型”与标准名词对应表中的“悬浮系统 → 悬浮系统（Float System）”等无直接对应，但“红莲可翔型”是机体名称，无需修改。
- [Design and Specifications] 术语“文森特·沃德”与标准名词对应表中的“第3世代 → 第三世代”等无直接对应，但“文森特·沃德”是机体名称，无需修改。
- [Design and Specifications] 术语“零之复活”与标准名词对应表中的“第3世代 → 第三世代”等无直接对应，但“零之复活”是剧情事件，无需修改。
- [Design and Specifications] 术语“无赖”与标准名词对应表中的“第3世代 → 第三世代”等无直接对应，但“无赖”是机体名称，无需修改。
