# 审核报告：Gekka (Crow version).json

### 文件：Gekka (Crow version).json
#### 问题列表
- [introduction] 术语“人型自在战斗装甲”与标准名词对应表中的“KMF”不一致，属于不同译名。 → 建议修改为“KMF”或“Knightmare Frame”。
- [specs.Fixed] 武装“飞燕爪式飞燕爪牙”表述存在逻辑混乱，疑似翻译错误或术语不标准。原作中月下通常配备“飞燕爪牙”（一种钩爪/锚索武器）。 → 建议修改为“1x 飞燕爪牙”。
- [specs.Handheld] 武装“旋转刃剑”疑似指代“MVS（微波振动剑）”，但“旋转刃剑”并非标准术语，且与“MVS”或“激光波动剑”等标准名词对应表内的术语不匹配。 → 建议根据原作设定，确认是否为MVS，并修改为“1x MVS（微波振动剑）”。
- [specs.Standard] 术语“陆地旋轮推进系统”与标准名词对应表中的“陆地旋轮 (Landspinner)”不一致，属于不同译名。 → 建议修改为“陆地旋轮 (Landspinner)”。
- [specs.Standard] 术语“驾驶舱弹射系统”与标准名词对应表一致，无问题。
- [specs.KMF Generation] 术语“相当于第七世代”中的“第七世代”与标准名词对应表一致，无问题。
