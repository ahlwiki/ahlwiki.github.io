# 审核报告：Chuyen.json

### 文件：Chuyen.json
#### 问题列表
- [introduction] “人型自在战斗装甲”应使用标准术语 → 建议修改为“KMF”
- [specs.KMF Generation] “相当于第七世代”表述不规范，应直接使用标准世代编号 → 建议修改为“第七世代”
- [specs.Standard] “履带式陆地旋轮推进系统”中的“履带式”为多余描述，且“陆地旋轮”为标准术语，但此处描述可能混淆 → 建议修改为“陆地旋轮推进系统”或“陆地旋轮”
- [specs.Fixed] “绳索式飞燕爪牙”中的“绳索式”可能为多余描述，且“飞燕爪牙”是否为标准武装名称需确认（原作中神虎有“飞燕爪牙”但通常无“绳索式”前缀） → 建议核实并统一为“飞燕爪牙”
- [specs.Handheld] “电磁如意金箍棒”是否为标准武装名称？原作中神虎的武装为“如意金箍棒”，未明确提及“电磁”属性 → 建议核实并修改为“如意金箍棒”
- [specs.Manga] “Code Geass 双貌的奥兹”中“双貌的奥兹”应为“双貌的OZ”或“双貌的奥兹”需确认标准译名 → 建议统一为“Code Geass 双貌的OZ”
- [Design and Specifications] “胸部粒子炮”中的“粒子炮”是否对应原作中神虎的“辐射波动”或“扩散式辐射波动”？需核实 → 建议修改为“胸部辐射波动炮”或根据原作设定调整
- [Trivia] “朱厌的设计基于孙悟空”表述可能不准确，朱厌为量产型神虎，神虎设计基于孙悟空，但朱厌本身是量产机 → 建议修改为“朱厌的设计基于神虎，而神虎的设计灵感来源于孙悟空”
