# 审核报告：Sutherland Custom (Ledo Machine).json

### 文件：Sutherland Custom (Ledo Machine).json
#### 问题列表
- [introduction] 术语“人型自在战斗装甲”与标准名词对应表中的“人型自在战斗装甲 → KMF”不一致，应直接使用标准术语“KMF”或全称“人型自在战斗装甲 (KMF)”。 → 建议修改为“萨瑟兰 (莱多机) 是莱多·奥芬的专用KMF。”或“萨瑟兰 (莱多机) 是莱多·奥芬的专用人型自在战斗装甲 (KMF)。”
- [specs.KMF Generation] 术语“第五世代”与标准名词对应表中的“第5世代 → 第五世代”不一致，应统一为“第五世代”。 → 建议修改为“第五世代”（当前已正确，无需修改，但需确认是否与标准表完全一致，标准表为“第5世代 → 第五世代”，此处已使用“第五世代”，符合要求）。
- [specs.Standard] 术语“事实球体传感器”与标准名词对应表中的“事实球面传感器 (Factsphere Sensor)”不一致，应为“事实球面传感器”。 → 建议修改为“事实球面传感器”。
- [specs.Standard] 术语“闪光护盾”与标准名词对应表中的“闪光护盾 → 卢米纳斯护盾 (Blaze Luminous)”不一致，应为“卢米纳斯护盾”。 → 建议修改为“卢米纳斯护盾”。
- [specs.Optional] 术语“悬浮系统”与标准名词对应表中的“悬浮系统（Float System）”一致，无需修改。
- [Design and Specifications] 术语“闪光护盾发生器”与标准名词对应表中的“闪光护盾 → 卢米纳斯护盾 (Blaze Luminous)”不一致，应为“卢米纳斯护盾发生器”。 → 建议修改为“卢米纳斯护盾发生器”。
- [Design and Specifications] 文本“为莱多个人使用而标准萨瑟兰的定制版本”存在语法不通和逻辑混乱问题，应为“为莱多个人使用而对标准萨瑟兰进行的定制版本”或“基于标准萨瑟兰为莱多个人使用的定制版本”。 → 建议修改为“基于标准萨瑟兰为莱多个人使用的定制版本。”
