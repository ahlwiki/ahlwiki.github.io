# 审核报告：Zi-Artemis.json

### 文件：Zi-Artemis.json
#### 问题列表
- [specs.Standard] 字段值为“陆地旋轮”，根据标准名词对应表，应使用“陆地旋轮 (Landspinner)”以明确术语。 → 建议修改为“陆地旋轮 (Landspinner)”
- [specs.Modes] 字段值为“堡垒模式”，该模式在《叛逆的鲁鲁修》系列中未出现，与已知设定不一致。 → 建议核实是否存在此模式，或修改为符合设定的模式（如“飞行模式”等）
- [specs.Power Source] 字段值为“尤克特拉希尔驱动（由能量填充器供能）”，原作中“尤克特拉希尔驱动”通常指能量填充器（Energy Filler）驱动的系统，但表述不完整。 → 建议修改为“能量填充器（Energy Filler）驱动的尤克特拉希尔系统”
- [specs.Armor Materials] 字段值为“钨”，原作中KMF装甲材料通常为“钨合金”或“复合装甲”，单一“钨”表述不准确。 → 建议修改为“钨合金”或“复合装甲”
- [specs.Developed Into] 字段值为“Zi-奥尔提吉亚”，该名称未在已知原作中出现，需确认是否为新机体或拼写错误。 → 建议核实名称或修改为已知机体
- [specs.Operators] 字段值为“无名佣兵”，原作中“罗泽”为明确角色，此处“无名佣兵”与“Known Pilots”中的“罗泽”矛盾。 → 建议统一为“罗泽”或删除“无名佣兵”
- [specs.Known Pilots] 字段值为“罗泽”，与“Operators”冲突，且“罗泽”为角色名，应统一。 → 建议将“Operators”修改为“罗泽”
- [image_variants] 字段值为“人形态”和“喷气机形态”，原作中KMF通常为“人形”和“飞行形态”，且“喷气机形态”与“堡垒模式”冲突。 → 建议修改为“人形”和“飞行形态”，并确保与“Modes”一致
- [introduction] 字段中“由罗泽驾驶的Knightmare Frame”与“Operators”中的“无名佣兵”矛盾。 → 建议统一为“由罗泽驾驶”
