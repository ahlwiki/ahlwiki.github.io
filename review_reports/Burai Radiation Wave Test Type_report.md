- [specs.KMF Generation] “第四世代”应使用标准术语“第四世代”。 → 建议修改为“第四世代”。
- [specs.Power Source] “尤克特拉希尔驱动”疑似拼写错误，应为“尤克特拉希尔驱动（Yggdrasil Drive）”。 → 建议修改为“尤克特拉希尔驱动（Yggdrasil Drive）”。
- [specs.Standard] “陆地旋轮”应使用标准术语“陆地旋轮 (Landspinner)”。 → 建议修改为“陆地旋轮 (Landspinner)”。
- [specs.Standard] “事实球体传感器”应使用标准术语“事实球面传感器 (Factsphere Sensor)”。 → 建议修改为“事实球面传感器 (Factsphere Sensor)”。
- [specs.Standard] “驾驶舱弹射系统”与标准术语一致，无问题。
- [introduction] “辐射波冲击”应为“辐射波动冲击（Radiation Wave Shock）”，与机体名称“辐射波动试验型”一致。 → 建议修改为“辐射波动冲击（Radiation Wave Shock）”。
- [Design and Development] “辐射波动臂”应为“辐射波动冲击臂（Radiation Wave Shock Arm）”，与设定一致。 → 建议修改为“辐射波动冲击臂（Radiation Wave Shock Arm）”。
