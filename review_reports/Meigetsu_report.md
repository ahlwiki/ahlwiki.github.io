# 审核报告：Meigetsu.json

### 文件：Meigetsu.json
#### 问题列表
- [specs -> Model Number] 型号 "Type-06" 与《叛逆的鲁鲁修》系列标准型号命名规则（如 Type-1 为“无赖”，Type-3 为“月下”）不一致，且“明月”作为黑色骑士团机体，通常为 Type-3 系列或更高世代，Type-06 在官方设定中无对应。 → 建议修改为 "Type-03" 或 "Type-3"（若为“月下”变体），或根据实际设定确认。
- [specs -> KMF Generation] "相当于第七世代" 表述模糊，原作中“明月”未明确标注世代，但“月下”系列为第七世代。 → 建议修改为 "第七世代"（去掉“相当于”以符合标准术语格式）。
- [specs -> Armor Materials] "钨" 作为装甲材料在《叛逆的鲁鲁修》中不常见，通常使用“樱石合金”或“碳纤维”。 → 建议修改为 "樱石合金" 或根据设定确认。
- [specs -> Standard] "红鬼装九头龙型陆地旋轮推进系统" 中的“红鬼装”和“九头龙型”非原作标准术语，且“陆地旋轮推进系统”应为“陆地旋轮”。 → 建议修改为 "陆地旋轮 (Landspinner)"，并移除“红鬼装九头龙型”或替换为官方设定。
- [specs -> Standard] "电磁飞翔滑走翼" 非原作标准术语，原作中类似装备为“浮空单元 (Float Unit)”或“飞翔滑走翼”。 → 建议修改为 "浮空单元 (Float Unit)" 或 "飞翔滑走翼"。
- [specs -> Standard] "辐射波护盾" 非原作标准术语，应为“卢米纳斯护盾 (Blaze Luminous)”。 → 建议修改为 "卢米纳斯护盾 (Blaze Luminous)"。
- [specs -> Fixed] "肩部手持刀片" 表述不通顺，且“手持刀片”非标准术语，可能指“MVS（微波振动剑）”或“实体剑”。 → 建议修改为 "肩部 MVS（微波振动剑）" 或根据设定确认。
- [specs -> Fixed] "臂装三管枪" 非原作标准术语，可能指“三管机枪”或“三管加农炮”。 → 建议修改为 "臂装三管机枪" 或根据设定确认。
- [specs -> Fixed] "飞燕爪型飞燕爪牙" 表述重复且不通顺，“飞燕爪牙”非标准术语，可能指“飞燕爪”或“钩爪”。 → 建议修改为 "飞燕爪 (Slash Harken)" 或根据设定确认。
- [specs -> Manga] "Code Geass 复活的鲁路修" 为剧场版而非漫画，且“明月”未在该作品中出现。 → 建议修改为 "Code Geass 反叛的鲁路修" 或根据实际出处确认。
- [specs -> Game] "Code Geass 反叛的鲁路修 R2 柏青哥游戏" 非官方主要作品，且“明月”可能为柏青哥原创机体，需注明非正史。 → 建议修改为 "Code Geass 反叛的鲁路修 R2 柏青哥游戏（非正史）"。
- [introduction] "人型自在战斗装甲 (KMF)" 术语正确，但“明月”在设定中为“月下”系列变体，需确认是否直接称为“KMF”。 → 无问题，但建议统一为 "KMF"。
- [Design and Development] "飞翔滑走翼" 非标准术语，同上。 → 建议修改为 "浮空单元 (Float Unit)" 或 "飞翔滑走翼"。
- [Design and Development] "辐射波护盾" 非标准术语，同上。 → 建议修改为 "卢米纳斯护盾 (Blaze Luminous)"。
- [Operational History] "与皇帝鲁鲁修交战" 与剧情矛盾，鲁鲁修在R2结局后未驾驶KMF参战，且“明月”在柏青哥游戏中可能为虚构剧情。 → 建议修改为 "在柏青哥游戏剧情中与皇帝鲁鲁修交战" 或删除此句。
- [Operational History] "富士山战役" 在《叛逆的鲁鲁修》中为关键战役，但“明月”未参与，需确认是否为柏青哥原创。 → 建议修改为 "在柏青哥游戏剧情中参与富士山战役"。
- [Trivia] "明月之名意为“哭泣之月”" 语义不通顺，且“明月”在日语中通常意为“明亮的月亮”，非“哭泣之月”。 → 建议修改为 "明月之名意为“明亮的月亮”" 或根据设定确认。
