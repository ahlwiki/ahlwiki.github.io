# 审核报告：Gekkoei Sui.json

### 文件：Gekkoei Sui.json
#### 问题列表
- [specs.KMF Generation] 术语“第七世代”与标准术语“第七世代”一致，但需确认原作中该机体是否确为第七世代。根据已知设定，月虹影帅（Gekkoei Sui）在《复活的鲁鲁修》中属于第七世代KMF，符合设定。
- [specs.Standard] 术语“悬浮单元”与标准术语“浮空单元（Float Unit）”不一致，属于近义词变体。 → 建议修改为“浮空单元（Float Unit）”。
- [specs.Fixed] 术语“光锥剑”与标准术语“MVS（Maser Vibration Sword，微波振动剑）”不一致，属于不同译名或描述。 → 建议修改为“MVS（Maser Vibration Sword，微波振动剑）”。
- [specs.Fixed] 术语“强子冲击炮”与标准术语无直接对应，但原作中月虹影帅未装备此武器，可能为设定错误或混淆。 → 建议核实是否为“强子炮（Hadron Cannon）”或删除该条目。
- [specs.Fixed] 术语“超扩散结构相转移重炮”与标准术语无对应，原作中月虹影帅未装备此武器，可能为原创或错误。 → 建议删除或替换为已知武装（如“扩散相转移炮”）。
- [specs.Manga] 字段“Manga”内容“Code Geass 复活的鲁路修”与标准术语不一致，应为“Code Geass: 复活的鲁鲁修”。 → 建议修改为“Code Geass: 复活的鲁鲁修”。
- [specs.Game] 字段“Game”内容“超级机器人大战30”与标准术语不一致，应为“超级机器人大战30”但需确认官方译名。 → 建议修改为“超级机器人大战30”（若为官方译名则保留）。
- [introduction] 文本“月虹影帅（月虹影帥）是月虹影的完成型”中“月虹影”与已知机体“月虹影（Gekkoei）”一致，但需确认“月虹影帅”是否为“月虹影”的完成型。根据设定，月虹影帅是月虹影的改进型，符合逻辑。
- [Trivia] 文本“在《Code Geass: 复活的鲁鲁修》的漫画改编版（与动画同一时间线的漫画）中完全取代了月虹影”中“取代”一词可能不准确，应为“作为升级版出现”。 → 建议修改为“作为月虹影的升级版出现”。
