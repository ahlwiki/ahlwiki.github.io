# 审核报告：Lancelot Albion Zero.json

### 文件：Lancelot Albion Zero.json
#### 问题列表
- [specs.Manufacturer] “珍珠派”不符合原作设定，应为“拉克夏塔”或“黑色骑士团技术部门”。 → 建议修改为“黑色骑士团（拉克夏塔）”
- [specs.Standard] “闪光护盾”应使用标准术语“卢米纳斯护盾 (Blaze Luminous)”。 → 建议修改为“卢米纳斯护盾 (Blaze Luminous)”
- [specs.Standard] “事实球体传感器”应为标准术语“事实球面传感器 (Factsphere Sensor)”。 → 建议修改为“事实球面传感器 (Factsphere Sensor)”
- [specs.Standard] “陆地旋轮”应补充标准术语“陆地旋轮 (Landspinner)”。 → 建议修改为“陆地旋轮 (Landspinner)”
- [specs.Handheld] “MVS (激光振动剑)”中“激光振动剑”非标准译名，应为“MVS（Maser Vibration Sword，微波振动剑）”。 → 建议修改为“MVS（Maser Vibration Sword，微波振动剑）”
- [specs.KMF Generation] “第九世代”符合标准，但需确认是否与设定一致（阿尔比昂原为第九世代，零式可能同代）。 → 无问题，但建议核对官方设定。
- [introduction] “人型自在战斗装甲 (KMF)”中“人型自在战斗装甲”应统一为标准术语“KMF”。 → 建议修改为“KMF”
- [Design and Development] “人型自在战斗装甲 (KMF)”同上。 → 建议修改为“KMF”
- [Operational History] “人型自在战斗装甲 (KMF)”同上。 → 建议修改为“KMF”
- [Operational History] “真幌羽零一式”和“真幌羽零一式”存在重复且名称疑似错误（应为“真幌羽零式”或“真幌羽零一式”？）。 → 建议核对官方名称，统一为“真幌羽零式”
- [Trivia] “枢木朱雀的早期加入机体”表述有歧义，阿尔比昂零式是ZERO的机体，与朱雀无关。 → 建议修改为“作为隐藏机体，若未获得，枢木朱雀将默认与鲁鲁修一同加入”
- [Trivia] “枢木朱雀”应为“枢木朱雀”，但需确认游戏设定中是否涉及朱雀驾驶。 → 建议核对游戏《超级机器人大战30》具体剧情，避免矛盾。
