# 审核报告：Zangetsu Flight-Enabled Version.json

### 文件：Zangetsu Flight-Enabled Version.json
#### 问题列表
- [name] 名称“斩月可翔式”与英文名“Zangetsu Flight-Enabled Version”不完全对应，且“可翔式”为日文汉字，中文语境下建议统一。 → 建议修改为“斩月（飞行装备型）”，或保留“斩月可翔式”但需在简介中说明。
- [specs.Classification] “空战指挥官型Knightmare Frame”中“Knightmare Frame”应使用标准术语。 → 建议修改为“空战指挥官型KMF”。
- [specs.KMF Generation] “相当于第七代”表述模糊，应直接使用标准世代编号。 → 建议修改为“第七世代”。
- [specs.Power Source] “尤克特拉希尔驱动”应为“樱石驱动”或“能量填充器”更符合原作设定（尤克特拉希尔是系统名，非能源）。 → 建议修改为“樱石驱动，由能量填充器供能”。
- [specs.Manufacturer] “贾巴尔普尔研究中心”应为“贾巴尔普尔研究中心”或“贾巴尔普尔基地”，但原作中黑色骑士团机体多由“拉克夏塔”团队开发，非特定研究中心。 → 建议修改为“黑色骑士团（拉克夏塔团队）”。
- [specs.Developed From] “晓量产型、晓·直参仕样”中“晓”应为“晓”或“晓·直参仕样”，但原作中“斩月”由“月下”发展而来，非“晓”。 → 建议修改为“月下（藤堂版）”。
- [specs.Operators] “超合众国”应为“超合众国”或“黑色骑士团”，但“超合众国”非直接操作组织。 → 建议修改为“黑色骑士团”。
- [specs.Known Pilots] “藤堂镜志朗”应为“藤堂镜志朗”，但原作中驾驶员为“藤堂镜志朗”，非“京四郎”。 → 建议修改为“藤堂镜志朗”。
- [specs.Standard] “驾驶舱弹射系统”正确；“辐射波动技术”应为“辐射屏障（Radiant Wave Shield）”；“可选飞翔滑走翼”应为“飞翔滑走翼（Float System）”。 → 建议修改为“驾驶舱弹射系统、辐射屏障、飞翔滑走翼”。
- [specs.Fixed] “2x 肩部机关炮”应为“2x 肩部机关炮”；“2x 飞燕爪牙”应为“2x 飞燕爪牙（Slash Harken）”；“1x 12管导弹发射器”应为“1x 12管导弹发射器”。 → 建议修改为“2x 肩部机关炮、2x 飞燕爪牙、1x 12管导弹发射器”。
- [specs.Anime] “《朱禁城的新娘》”应为“《朱禁城的新娘》”；“《达摩克利斯之剑》”应为“《达摩克利斯之剑》”。 → 无问题，但建议确认是否为正式译名。
- [introduction] “由藤堂京四郎驾驶”中“京四郎”应为“镜志朗”。 → 建议修改为“由藤堂镜志朗驾驶”。
- [introduction] “飞翔滑走翼”正确，但“无辅助飞行”应为“独立飞行”。 → 建议修改为“可以进行独立飞行和空中战斗”。
- [Design and Specifications] “拉克沙塔·恰拉”应为“拉克夏塔·恰拉”。 → 建议修改为“拉克夏塔·恰拉”。
- [Design and Specifications] “月下”应为“月下”；“青道刃妖剑斩鹤刀”应为“斩鹤刀（青道刃妖剑）”。 → 建议修改为“斩鹤刀（青道刃妖剑）”。
- [Design and Specifications] “冲击扩散柔性纤维”应为“冲击扩散柔性纤维（Impact Diffusion Flexible Fiber）”。 → 建议修改为“冲击扩散柔性纤维”。
