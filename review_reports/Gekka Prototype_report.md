# 审核报告：Gekka Prototype.json

### 文件：Gekka Prototype.json
#### 问题列表
- [introduction] “人型自在战斗装甲”与标准术语“KMF”不一致 → 建议修改为“KMF”
- [Design and Specifications] “人型自在战斗装甲 (KMF)”中括号内为英文缩写，但“人型自在战斗装甲”本身非标准术语 → 建议直接使用“KMF”
- [introduction] “Code Geass: 叛逆的鲁鲁修 - Lost Colors”游戏名称中的“叛逆的鲁鲁修”与官方译名“反叛的鲁鲁修”存在差异（模糊匹配） → 建议修改为“Code Geass: 反叛的鲁鲁修 - Lost Colors”
- [specs] “KMF Generation”字段值为“相当于第七世代”，但标准术语为“第七世代”（无“相当于”前缀） → 建议修改为“第七世代”
- [specs] “能量填充器”非标准术语，原作中通常称为“能量填充器（Energy Filler）”或“能量罐” → 建议修改为“能量填充器（Energy Filler）”
- [specs] “背部内置干扰烟雾散布系统”中的“干扰烟雾”非标准术语，原作中通常称为“烟雾弹”或“干扰烟雾弹” → 建议修改为“干扰烟雾弹散布系统”
- [specs] “飞燕爪式斩击钩锚”非标准术语，原作中月下系列通常装备“飞燕爪牙”或“钩锚” → 建议修改为“飞燕爪牙（钩锚）”
- [specs] “旋转刃剑”非标准术语，原作中月下系列通常装备“旋转刃刀”或“MVS” → 建议修改为“旋转刃刀（MVS）”
- [specs] “定制手枪”非标准术语，原作中月下系列通常装备“手枪”或“专用手枪” → 建议修改为“专用手枪”
- [Design and Specifications] “红莲辐射波单元”非标准术语，原作中红莲贰式装备“辐射波单元（Radiant Wave Unit）” → 建议修改为“辐射波单元（Radiant Wave Unit）”
- [Operational History] “格洛斯特”非标准术语，原作中为“格洛斯特（Gloucester）” → 建议修改为“格洛斯特（Gloucester）”
- [Operational History] “横须贺港战役”中的“横须贺港”非标准地名，原作中为“横须贺”或“横须贺港”均可，但建议统一为“横须贺” → 建议修改为“横须贺战役”
