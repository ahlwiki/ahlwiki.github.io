# 审核报告：Guren Type Special.json

### 文件：Guren Type Special.json
#### 问题列表
- [specs.KMF Generation] 术语不一致：使用“第九世代”，标准应为“第九世代”（已匹配，但需确认标准对应表为“第九世代”而非“第9世代”，此处无问题）。
- [specs.Standard] 术语不一致：“陆地旋轮推进系统”应模糊匹配为“陆地旋轮 (Landspinner)”；“事实球体传感器”应模糊匹配为“事实球面传感器 (Factsphere Sensor)”；“飞翔滑走翼改”非标准术语，建议根据上下文匹配为“浮空单元（Float Unit）”或“能量翼”相关术语，但标准表中无直接对应，需确认是否为“悬浮系统”或“浮空单元”；“辐射波护盾”应模糊匹配为“卢米纳斯护盾 (Blaze Luminous)”。
  → 修改建议：将“陆地旋轮推进系统”改为“陆地旋轮 (Landspinner)”；将“事实球体传感器”改为“事实球面传感器 (Factsphere Sensor)”；将“飞翔滑走翼改”根据设定改为“浮空单元（Float Unit）”或“能量翼”；将“辐射波护盾”改为“卢米纳斯护盾 (Blaze Luminous)”。
- [specs.Fixed] 术语不一致：“复合导向飞燕·苍鸦式飞燕爪牙”非标准术语，建议根据原作设定改为“飞燕爪牙（可伸缩）”或类似描述；“辐射推进自由式有线穿甲轰炸右臂”非标准术语，建议改为“辐射波动式右臂（有线式）”或“辐射推进式右臂”。
  → 修改建议：将“复合导向飞燕·苍鸦式飞燕爪牙”改为“飞燕爪牙（可伸缩）”；将“辐射推进自由式有线穿甲轰炸右臂”改为“辐射波动式右臂（有线式）”。
- [specs.Handheld] 术语一致：使用“MVS”，符合标准对应表（MVS（Maser Vibration Sword，微波振动剑））。
- [Design and Development] 术语不一致：“人型自在战斗装甲”应模糊匹配为“KMF”；“辐射屏障”应模糊匹配为“卢米纳斯护盾 (Blaze Luminous)”。
  → 修改建议：将“人型自在战斗装甲”改为“KMF”；将“辐射屏障”改为“卢米纳斯护盾 (Blaze Luminous)”。
- [Operational History] 术语不一致：“人型自在战斗装甲”出现两次，应模糊匹配为“KMF”；“框架涂层”非标准术语，建议根据设定改为“能量涂层”或“辐射涂层”；“MVS热斩刀”中“MVS”已匹配，但“热斩刀”需确认是否为标准名称，建议改为“MVS（试制壹式·热斩刀）”。
  → 修改建议：将两处“人型自在战斗装甲”改为“KMF”；将“框架涂层”改为“能量涂层”或“辐射涂层”；将“MVS热斩刀”改为“MVS（试制壹式·热斩刀）”。
- [introduction] 语义通顺性：“代号‘Kaen Kohai’”中“Kaen Kohai”为日语罗马音，但未在标准名词对应表中，建议确认是否为官方代号，若无问题则保留。
- [specs.Developed From] 剧情设定一致性：“红莲圣天八极式”为原作机体，符合设定，无问题。
- [specs.Manufacturer] 剧情设定一致性：“珍珠派”为《复活的鲁鲁修》中组织，符合设定，无问题。
- [specs.Known Pilots] 剧情设定一致性：“卡莲·休妲菲尔特”为原作角色，符合设定，无问题。
