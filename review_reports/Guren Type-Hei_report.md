# 审核报告：Guren Type-Hei.json

### 文件：Guren Type-Hei.json
#### 问题列表
- [specs.KMF Generation] 世代描述不一致 → 建议将“第七世代”修改为“第七世代”（标准术语为“第七世代”，当前写法正确，但需确认是否与标准表一致，此处无问题）。
- [introduction] 术语“人型自在战斗装甲”与标准术语不一致 → 建议修改为“KMF”或“Knightmare Frame”。
- [specs.Developed From] 名称“红莲贰式”需确认是否与标准译名一致（如“红莲二式”） → 建议根据官方设定统一为“红莲二式”（若标准译名为“红莲贰式”则保留）。
- [specs.Known Pilots] 驾驶员“扇要”和“玉城真一郎”需确认是否与剧情设定一致（原作中红莲丙式主要由扇要驾驶，玉城真一郎驾驶红莲可翔式） → 建议核实剧情，若玉城真一郎未驾驶过丙式，则删除或修改。
- [specs.Manufacturer] 制造商“印度军事区”需确认是否与设定一致（红莲系列由京都六家委托印度军区开发） → 建议修改为“印度军区”或“印度军事区”（需根据官方设定统一）。
- [specs.Power Source] “能量填充器”术语需确认是否标准 → 建议修改为“能量填充器”（若标准术语为“能量填充器”则保留，否则调整）。
- [specs.Armor Materials] 装甲材料“钨”需确认是否与设定一致（红莲系列使用钨合金） → 建议修改为“钨合金”以更准确。
- [specs.Overall Height] 高度“4.51 米”需确认是否与设定一致（红莲丙式高度约为4.5米） → 建议核实官方数据，若一致则保留。
