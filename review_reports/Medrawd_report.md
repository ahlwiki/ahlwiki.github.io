# 审核报告：Medrawd.json

### 文件：Medrawd.json
#### 问题列表
- [name] 名称“梅德拉乌德”与英文名“Medrawd”及背景介绍中的“梅德劳德”不一致 → 统一名称为“梅德拉乌德”或根据官方译名修正。
- [specs.Developed From] “莫德雷德强化型”中的“莫德雷德”应为标准译名“莫德雷德”（Mordred），但此处与“强化型”组合，需确认是否指“莫德雷德”的强化版本，若为衍生型号，建议明确为“莫德雷德（强化型）”。
- [specs.Known Pilots] 驾驶员“C.C.”在设定中未驾驶过此机体，且背景介绍提到“玛丽安娜原本打算让它由C.C.使用”，但状态为“未使用”，存在矛盾 → 建议修改为“无（未使用）”或注明“计划驾驶员：C.C.”。
- [specs.Standard] “综合悬浮系统”应为标准术语“悬浮系统（Float System）”；“闪光护盾”应为“卢米纳斯护盾 (Blaze Luminous)”。
- [specs.Fixed] “小型近程导弹发射器”中的“近程”应为“近程”（拼写错误，应为“近程”或“短程”），建议修正为“小型短程导弹发射器”。
- [introduction] “人型自在战斗装甲”应为标准术语“KMF”；“梅德劳德”与名称“梅德拉乌德”不一致 → 统一为“梅德拉乌德”。
- [introduction] “应玛丽安娜的要求，通过阿尼亚·阿尔斯特雷姆建造”表述逻辑不清，阿尼亚是玛丽安娜的女儿，但此处“通过”可能指阿尼亚参与建造，需确认是否准确 → 建议改为“由玛丽安娜委托，阿尼亚·阿尔斯特雷姆协助建造”或根据设定修正。
