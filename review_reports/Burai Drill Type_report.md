# 审核报告：Burai Drill Type.json

### 文件：Burai Drill Type.json
#### 问题列表
- [specs.Classification] 术语“人型自在战斗装甲”与标准名词对应表中的“人型自在战斗装甲 → KMF”不一致，应使用标准术语“KMF”。 → 建议修改为“改装型近战KMF”或“改装型近战人型自在战斗装甲 (KMF)”，但根据标准表，应优先使用“KMF”。
- [specs.KMF Generation] 术语“第四世代”与标准名词对应表中的“第4世代 → 第四世代”不一致，应使用“第四世代”。 → 建议修改为“第四世代”（当前已是“第四世代”，无问题，但需确认标准表要求“第四世代”而非“第4世代”，当前正确）。
- [introduction] 术语“人型自在战斗装甲”出现两次，与标准名词对应表不一致。 → 建议将两处“人型自在战斗装甲”均修改为“KMF”。
- [Design and Development] 术语“飞燕爪牙”未在标准名词对应表中列出，但根据《叛逆的鲁鲁修》设定，无赖的标准武装包括“飞燕爪牙”（Slash Harken），术语正确，无需修改。
- [Design and Development] 术语“钻头臂”未在标准名词对应表中列出，但作为改装型机体的特有武装，符合设定，无需修改。
- [specs.Power Source] 术语“尤克特拉希尔驱动”未在标准名词对应表中列出，但根据《叛逆的鲁鲁修》设定，KMF的动力源为“尤克特拉希尔驱动”（Yggdrasil Drive），术语正确，无需修改。
- [specs.Armor Materials] 术语“钨”未在标准名词对应表中列出，但根据设定，无赖的装甲材料为钨钢（Tungsten），术语正确，无需修改。
- [specs.Developed From] 术语“无赖”未在标准名词对应表中列出，但根据设定，无赖（Burai）是标准机体名称，术语正确，无需修改。
- [specs.Operators] 术语“黑色骑士团”未在标准名词对应表中列出，但根据设定，黑色骑士团（Black Knights）是标准组织名称，术语正确，无需修改。
- [specs.Game] 术语“Code Geass DS”未在标准名词对应表中列出，但作为游戏名称，无需修改。

**总结**：主要问题在于术语“人型自在战斗装甲”未按标准表替换为“KMF”，以及“第四世代”已正确，但需确认其他字段无标准术语冲突。建议统一将“人型自在战斗装甲”修改为“KMF”。
