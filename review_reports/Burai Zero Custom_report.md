# 审核报告：Burai Zero Custom.json

### 文件：Burai Zero Custom.json
#### 问题列表
- [specs.KMF Generation] 术语不一致：“第四世代”与标准名词对应表中的“第四世代”匹配，但标准表要求使用“第四世代”而非“第四世代”，此处无问题。实际检查发现“第四世代”与标准表“第四世代”一致，无需修改。但标准表要求使用中文数字“第四世代”，而JSON中为“第四世代”，符合要求。
- [specs.Standard] 术语不一致：“陆地旋轮”与标准名词对应表中的“陆地旋轮 (Landspinner)”匹配，但标准表要求使用“陆地旋轮 (Landspinner)”，此处缺少英文注释。建议修改为“陆地旋轮 (Landspinner)”。
- [specs.Standard] 术语不一致：“事实球体传感器”与标准名词对应表中的“事实球面传感器 (Factsphere Sensor)”不匹配。建议修改为“事实球面传感器 (Factsphere Sensor)”。
- [specs.Fixed] 术语不一致：“飞燕爪牙”非标准术语，原作中应为“飞燕爪牙 (Slash Harken)”。建议修改为“飞燕爪牙 (Slash Harken)”。
- [specs.Fixed] 术语不一致：“保护者”非标准术语，原作中应为“保护者 (Protector)”，但通常指“手部保护者 (Hand Protector)”。建议修改为“手部保护者 (Hand Protector)”。
- [specs.Fixed] 术语不一致：“躯干安装机枪”非标准术语，原作中无此武装，无赖标准武装为“胸部机枪 (Chest Machine Gun)”。建议修改为“胸部机枪 (Chest Machine Gun)”。
- [specs.Handheld] 术语不一致：“防暴盾”非标准术语，原作中应为“防暴盾 (Riot Shield)”。建议修改为“防暴盾 (Riot Shield)”。
- [specs.Power Source] 语义通顺性：“尤克特拉希尔驱动”应为“尤克特拉希尔驱动 (Yggdrasil Drive)”，但“由能量填充器供能”表述不准确，原作中KMF由“能量填充器 (Energy Filler)”供能，但通常描述为“尤克特拉希尔驱动，由能量填充器供能”可接受。无修改建议。
- [introduction] 语义通顺性：“無頼（ゼロ機）”中的括号使用日语括号，建议统一为中文括号“无赖（ZERO机）”。
- [Design and Development] 剧情设定一致性：描述“在功能上与标准型无赖完全相同”基本正确，但ZERO机无赖在涂装和头部模块上有区别，且可能配备特殊系统（如自爆装置）。建议补充说明“除头部模块和涂装外，基本性能与标准无赖一致”。
- [Operational History] 剧情设定一致性：“成田战役”应为“成田连山战役”或“成田攻防战”。建议修改为“成田连山战役”。
