# 审核报告：Elphaba.json

### 文件：Elphaba.json
#### 问题列表
- [specs.KMF Generation] "KMF巨型要塞" 不符合原作世代划分标准，且与标准术语不匹配。 → 建议修改为“巨型要塞”或根据设定指定具体世代（如“第七世代”），但“KMF巨型要塞”非标准表述。
- [specs.Power Source] "尤克特拉希尔驱动" 存在拼写或译名不一致，标准术语应为“尤克特拉希尔驱动系统（Yggdrasil Drive）”。 → 建议修改为“尤克特拉希尔驱动系统（Yggdrasil Drive）”。
- [specs.Armor Materials] "钨" 过于笼统，原作中KMF装甲多为“钨合金”或“樱石混合装甲”。 → 建议修改为“钨合金”以符合常见设定。
- [specs.Developed From] "兰斯洛特·试作" 表述不标准，应为“兰斯洛特试作机”或“兰斯洛特原型机”。 → 建议修改为“兰斯洛特试作机”。
- [specs.Standard] "闪光护盾" 与标准术语“卢米纳斯护盾 (Blaze Luminous)”不匹配。 → 建议修改为“卢米纳斯护盾 (Blaze Luminous)”。
- [specs.Standard] "绝对防御系统" 非标准术语，原作中类似系统为“绝对防御领域（Absolute Defense Field）”。 → 建议修改为“绝对防御领域（Absolute Defense Field）”。
- [specs.Standard] "悬浮系统" 与标准术语“悬浮系统（Float System）”一致，但需确认是否指代浮空单元。 → 无需修改，但可补充说明为“悬浮系统（Float System）”。
- [specs.Fixed] "超强子加农炮" 非标准术语，原作中类似武器为“强子加农炮（Hadron Cannon）”。 → 建议修改为“强子加农炮（Hadron Cannon）”。
- [specs.Fixed] "扩散强子炮" 非标准术语，应为“扩散强子炮（Diffusion Hadron Cannon）”。 → 建议修改为“扩散强子炮（Diffusion Hadron Cannon）”。
- [specs.Handheld] "MVS (激光振动剑)" 与标准术语“MVS（Maser Vibration Sword，微波振动剑）”不一致，且“激光振动剑”为错误译名。 → 建议修改为“MVS（Maser Vibration Sword，微波振动剑）”。
- [specs.Handheld] "可变弹药反冲冲击喷射枪 (VARIS)" 标准术语为“可变弹药反冲冲击喷射枪（VARIS）”，但需确认拼写是否准确（通常为“VARIS”）。 → 建议保留，但确认“反冲”应为“反冲”或“后坐力”，无大问题。
- [introduction] "艾尔法巴" 与JSON中名称“埃尔法巴”不一致，需统一。 → 建议统一为“埃尔法巴”或“艾尔法巴”，根据官方译名决定。
- [introduction] "骑士巨型要塞" 非标准术语，且与specs中“KMF巨型要塞”矛盾。 → 建议统一为“巨型要塞”或“KMF要塞”。
- [introduction] "由鲁鲁修赠予玛丽贝尔" 与《双貌的奥兹》剧情设定不符：埃尔法巴实际由玛丽贝尔·梅尔·布列塔尼亚驾驶，但开发者与赠予者需核实。 → 建议根据原作设定修改为“由不列颠尼亚开发，后由鲁鲁修赠予玛丽贝尔”或删除“由鲁鲁修赠予”以保持准确性。
- [Design and Specifications] "艾尔法巴" 与名称“埃尔法巴”不一致。 → 建议统一为“埃尔法巴”。
- [Design and Specifications] "长矛型钩爪" 非标准描述，原作中萨瑟兰的武装为“钩爪”或“长矛”。 → 建议修改为“长矛型钩爪”或“钩爪”，但需确认具体设定。
- [Design and Specifications] "模块化手部" 表述可接受，但建议使用标准术语“模块化手臂”或“可替换手部”。 → 建议修改为“模块化手臂”。
